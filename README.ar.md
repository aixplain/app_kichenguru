# KitchenGuru

مرحبًا بك في KitchenGuru، تطبيق قوي لتوليد الوصفات مدعوم بالذكاء الاصطناعي ومبني باستخدام Swift وأحدث إصدار من SDK الخاص بـ aiXplainKit. يوضح هذا المشروع كيفية دمج النماذج الذكية بسلاسة في تطبيقات iOS.

تابع João Pedro Maia (مطور برمجيات في aiXplain) وهو يوضح لك كيفية دمج الذكاء الاصطناعي في تطبيقات IOS الخاصة بك.
